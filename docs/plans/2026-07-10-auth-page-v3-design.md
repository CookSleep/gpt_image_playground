# 登录页 V3 设计

## 目标

让登录页与已确认的浅色未来感工作台保持统一，同时保持工具型定位，不做营销落地页。

## 页面结构

- 左侧为产品身份和创作任务预览，展示一张已完成图片和一张生成中图片。
- 右侧为独立登录面板，只保留邮箱、密码、错误提示和登录按钮。
- 页面底部明确说明账号认证、API Key 和计费由 sub2api 管理，浏览器不保存 API Key 明文。

## 文案

- 标题：登录极简生图
- 说明：使用你的 sub2api 账号进入图片工作台。
- 按钮：登录并进入工作台
- 加载状态：正在验证账号…
- 左侧主标题：专注图片生成，从描述到成图只需一个页面。

## 边界

- 不新增注册、找回密码、第三方登录等当前不可用入口。
- 不修改 `/api/auth/login` 接口、请求字段和登录状态管理。
- 同步优化账号停用页面的文案和视觉，但不改变刷新和退出行为。
