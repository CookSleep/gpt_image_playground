# Aurora 全站视觉规范

## 目标

在不改变 Aurora Studio 现有配色、字体和页面结构的前提下，统一登录后工作台的控件高度、垂直居中、间距节奏、文字层级和响应式行为，消除由全局固定按钮高度引起的内容溢出。

## 适用范围

- 顶部品牌、主导航、额度、主题、设置和退出工具区
- 我的作品页
- 创作工作台及生成结果侧栏
- 图片资产页
- 设置、详情、提示词优化和删除确认弹窗
- 390px 移动端与桌面端布局

## 基础令牌

所有 Aurora 页面使用同一组 CSS 变量：

| 类型 | 变量 | 值 | 用途 |
| --- | --- | --- | --- |
| 紧凑控件 | `--ui-control-compact` | `28px` | 主题分段按钮 |
| 标准控件 | `--ui-control-standard` | `36px` | 导航、图标按钮、筛选按钮 |
| 表单控件 | `--ui-control-input` | `40px` | 输入框、下拉框 |
| 主要操作 | `--ui-control-primary` | `44px` | 保存、创建等主要命令 |
| 紧凑间距 | `--ui-space-1` | `8px` | 同组控件间距 |
| 常规间距 | `--ui-space-2` | `12px` | 控件与相邻内容间距 |
| 区块间距 | `--ui-space-3` | `16px` | 页面区块间距 |

页面级留白继续使用既有 `--space-page` 和 `--space-panel`，避免扩大本次改动范围。

## 组件规范

### 顶部工具区

- 顶部栏桌面高度保持 `72px`，所有直接控件围绕同一中心线对齐。
- 额度文字、主题切换、设置按钮和退出按钮的占位高度统一为 `36px`。
- 工具组内间距统一为 `8px`；额度文字与交互控件之间保留额外 `4px` 呼吸空间。
- 设置和退出均为 `36px × 36px` 图标按钮；主题容器高度为 `36px`，内部按钮为 `28px`。
- 纯图标按钮必须清除全局文本按钮 padding，使用 `padding: 0` 和中心布局；图标中心与按钮中心在两个轴上的偏差不得超过 `1px`。
- 移动端保持品牌与工具区第一行、主导航第二行，不允许横向溢出。

### 创作设置入口

- 入口使用 `height: auto`，最小高度 `58px`，不得继承全局 `button` 的 `38px` 固定高度。
- 内容采用图标、文本、箭头三列网格，三列垂直居中。
- 主文案使用控件字号和明确行高；副文案保持一行优先，空间不足时自然换行且按钮同步增高。
- 与标题和提示词区的间距分别由标题既有下边距和 `12px` 下边距承担。

### 任务列表

- 任务行使用 `height: auto`，最小高度 `82px`，内容不得因全局按钮高度被裁切。
- 标题最多两行，状态或错误信息允许两行；超长内容由行内截断规则控制。
- 缩略图、文字和状态围绕同一垂直中心排列。

### 表单与弹窗

- 输入框和下拉框保持至少 `40px` 高；主要操作保持至少 `44px` 高。
- 弹窗标题区、正文和页脚沿用现有结构，桌面端居中，移动端宽度不超过视口减 `24px`。
- 弹窗允许纵向滚动，不允许横向滚动或文字越界。

## 页面节奏

- 同组控件使用 `8px`。
- 控件与说明、相邻控件块使用 `12px`。
- 独立页面区块使用 `16px` 或既有页面级留白。
- 不为单个页面引入新的任意间距值；确有必要时优先复用现有令牌。

## 响应式规范

- 桌面检查宽度：`1536px` 及以上。
- 移动检查宽度：`390px`，高度 `844px`。
- 所有页面必须满足 `scrollWidth <= clientWidth`。
- 文本型按钮必须满足内容高度不超过控件可视高度，滚动容器除外。
- 临时移动视口验证结束后恢复浏览器默认视口。

## 验收标准

1. 创作设置入口副文案完整位于按钮边框内，图标、文字和箭头垂直居中。
2. 顶部额度、主题、设置和退出控件在桌面与移动端保持统一高度与间距。
3. 生成结果任务行没有 3px 内容裁切。
4. 我的作品、创作工作台、图片资产、设置弹窗和任务详情均无横向溢出。
5. 现有业务行为、设置门禁、数据持久化和 API 调用保持不变。
