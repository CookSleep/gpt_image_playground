# 报告安全漏洞

如果你发现 GPT Image Playground 存在安全漏洞，请通过 GitHub [私下报告漏洞](https://github.com/CookSleep/gpt_image_playground/security/advisories/new)。

本项目不提供漏洞赏金。维护者精力有限，核实和修复问题可能需要一些时间。感谢你花时间调查并报告问题。

## Reporting a security vulnerability

If you discover a security vulnerability in GPT Image Playground, please [report it privately on GitHub](https://github.com/CookSleep/gpt_image_playground/security/advisories/new).

This project does not offer bug bounties. The maintainer has limited time, so investigating and fixing a vulnerability may take a while. Thank you for taking the time to investigate and report it.
